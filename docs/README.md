Running the native IPC benchmarks creates `artifacts/cpp_zmq_ipc_oneway_benchmark.json` and `artifacts/shm_spsc_ipc_benchmark.json` with separate latency charts. The shared-memory report checks that the atomics are lock-free before the result is reported. The DuckDB batch-size sweep compares 1K, 10K, and 50K row batches after a warm-up and verifies each database read-back. Running the DuckDB stress test also writes `artifacts/storage_benchmark.json` and generates `assets/storage-benchmark.svg`. Run `python scripts/validate_reports.py` to check the JSON/CSV invariants and SVG files. Benchmark values depend on the machine and selected tick count.
